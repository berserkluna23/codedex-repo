01 — Esencia

¿Qué es Codedex.io?

Es una plataforma para aprender programación desde cero o reforzar habilidades mediante lecciones breves, ejercicios y proyectos. Su enfoque hace que practicar código se sienta como avanzar en un juego.

Puedes explorar tecnologías como Python, HTML, CSS, JavaScript, SQL, Git y más, a tu propio ritmo y desde el navegador.
